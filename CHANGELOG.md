# Changelog

## 1.0.0 — 2026-11-12

First version.

- Edge tab on any screen edge; drag to move; opens the panel on hover or click.
- Floating Liquid Glass panel with the tasks of the day: add, complete (animation and
  sound), edit, change order, delete, focus task, move to tomorrow.
- Pin the panel above all windows, Spaces, and full-screen apps.
- Global shortcut (default Control + Option + M) for fast capture.
- One list for each day; history; morning review of open tasks from the last day.
- Notes: one current note, an archive of saved notes.
- Menu bar icon and Settings.
- Plain Markdown files in `~/Margin`, the `margin` command, and an MCP server for AI agents.
