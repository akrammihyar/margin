# Margin 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Margin, a native macOS app that keeps the task list of the day in a hover panel at the screen edge, with notes, a CLI, and an MCP server for local AI agents.

**Architecture:** One Swift package. `MarginCore` (library) owns the Markdown file format, the store, day logic, notes, and pure screen-edge geometry. `MarginCommands` (library) owns the CLI command runner and the MCP server. `margin` (executable) is a thin `main` over `MarginCommands`. `MarginApp` (executable) is an AppKit accessory app with SwiftUI views in floating panels. All of them read and write the same files in `~/Margin/`; the app watches the folder for changes.

**Tech Stack:** Swift 6.x (Command Line Tools for Xcode 26.6, macOS 26 SDK), SwiftPM, SwiftUI + AppKit, Swift Testing. No third-party dependencies. No Xcode project.

**Spec:** `docs/superpowers/specs/2026-11-12-margin-design.md` — read it before each task.

## Global Constraints

- Minimum system macOS 26. Apple silicon. Build with `swift build`; full Xcode is not available.
- Zero third-party dependencies.
- No network use in any target.
- No repeating timers and no polling anywhere. One-shot delays (`DispatchWorkItem`) are permitted for the 150 ms open delay, the 300 ms close delay, and the 1 s note autosave.
- Data folder: `~/Margin/`, replaced by the environment variable `MARGIN_HOME` when it is set. Tests always use a temporary folder.
- All file writes are atomic (temporary file, then rename). Each store operation reads the file from disk again immediately before it changes it.
- Task text is one line. Tags `@now`, `@done(HH:MM)`, `@moved(YYYY-MM-DD)` are parsed only at the end of the line.
- Lines in a day file that are not task lines are kept unchanged and in position.
- Default shortcut: Control + Option + M. Hover open delay 150 ms. Hover close delay 300 ms. Panel width 300 pt, maximum height 70% of the visible screen height.
- The product name is in one constant per target (`AppInfo.name`). No personal data, user names, or absolute user paths in the repository.
- The file system is case-insensitive: the app binary `Margin` and the CLI binary `margin` must never be in the same folder.
- Record each decision that is not in the spec in `docs/DECISIONS.md` (date, decision, reason).
- Commit after each task with a conventional commit message. Do not push and do not create a GitHub repository.

## Review Focus

1. **Two writers at the same time.** An agent runs `margin add` while the panel is open, or while the owner is editing a task. Expected: no task is lost, and the text that the owner is typing is not thrown away. → tests in Task 3 (`operationRereadsDisk`) and manual check in Task 9.
2. **Unusual task text.** Pasted text with line breaks, text that is only spaces, text with `@now` or `[ ]` in the middle, emoji, Arabic (right-to-left) text. Expected: line breaks become spaces, empty text is rejected, middle tags stay as text, the text survives a write-read cycle unchanged. → tests in Task 2 and Task 3.
3. **Data folder missing or not writable while the app runs.** The owner deletes `~/Margin/` or a day file. Expected: the folder is created again on the next write, a missing day reads as empty, and the app shows an error text and does not crash. → tests in Task 3; error display in Task 9.
4. **Sleep through one or more midnights, or a time zone change.** Expected: "today" is always computed at the time of the operation, and the review banner shows the most recent earlier day with open tasks. → tests in Task 4.
5. **Display changes.** The display of the tab is disconnected, the resolution changes, the tab is in a corner, the panel is taller than the screen. Expected: the tab and panel are always fully on a connected screen. → tests in Task 7.

### Task 2: DayID and the day file format

**Files:** Create `Sources/MarginCore/DayID.swift`, `TaskItem.swift`, `DayFile.swift`; tests `Tests/MarginCoreTests/DayIDTests.swift`, `DayFileTests.swift`.

**Interfaces — Produces:**
```swift
public struct DayID: Hashable, Comparable, Sendable, CustomStringConvertible {
    public let year: Int, month: Int, day: Int
    public init?(_ string: String)                       // "2026-11-12" only; rejects invalid dates
    public init(date: Date, calendar: Calendar)
    public var description: String                       // "2026-11-12"
    public func adding(days: Int, calendar: Calendar) -> DayID
    public func date(calendar: Calendar) -> Date         // local midnight
}
public enum TaskState: String, Sendable { case open, done, archived, moved }
public struct TaskItem: Equatable, Sendable {
    public var text: String
    public var state: TaskState
    public var isFocus: Bool
    public var doneAt: String?        // "HH:MM"
    public var movedTo: DayID?
    public init(text: String, state: TaskState = .open, isFocus: Bool = false, doneAt: String? = nil, movedTo: DayID? = nil)
}
public enum DayLine: Equatable, Sendable { case task(TaskItem), other(String) }
public struct DayFile: Equatable, Sendable {
    public let day: DayID
    public var lines: [DayLine]
    public var tasks: [TaskItem] { get }                 // task lines in order
    public init(day: DayID)                              // lines = [.other("# <day>"), .other("")]
    public static func parse(_ text: String, day: DayID) -> DayFile
    public func render() -> String                       // ends with one "\n"
    public func lineIndex(ofTask n: Int) -> Int?         // n is 0-based among task lines
}
```

Parser rules (from spec 6.3): a task line matches `^\s*[-*]\s+\[( |x|X|~|>)\]\s+(.*)$`. Strip tags from the end repeatedly, in any order: `@now`, `@done(HH:MM)`, `@moved(YYYY-MM-DD)`. `[x]` without `@done` gives `doneAt == nil`. More than one `@now` in a file: only the first task keeps `isFocus`. Every other line, including the `# date` header and blank lines, is `.other(original text)`. Render writes tasks as `- [m] text` + ` @now` + ` @done(..)` + ` @moved(..)` in that order; `isFocus` is written only for state `.open`.

### Task 3: Store and task operations

**Files:** Create `Sources/MarginCore/Store.swift`; add `TaskRef`, `MarginError` to `TaskItem.swift`; tests `Tests/MarginCoreTests/StoreTests.swift`.

**Interfaces — Consumes:** Task 2 types. **Produces:**
```swift
public enum TaskRef: Equatable, Sendable { case number(Int)   // 1-based among all task lines of the day
                                           case text(String) } // case-insensitive fragment; must match exactly one task
public enum MarginError: Error, Equatable, CustomStringConvertible {
    case notFound(String), ambiguous(String, matches: [String]), emptyText, invalidDate(String), invalidPosition(Int), io(String)
}
public final class Store: @unchecked Sendable {
    public let root: URL
    public init(root: URL = Store.defaultRoot(), clock: @escaping @Sendable () -> Date = { Date() }, calendar: Calendar = .current)
    public static func defaultRoot() -> URL              // $MARGIN_HOME or ~/Margin
    public var calendar: Calendar { get }
    public func today() -> DayID
    public func now() -> Date
    public func url(for day: DayID) -> URL               // root/days/<day>.md
    public func load(_ day: DayID) throws -> DayFile     // missing file -> DayFile(day:) (nothing written)
    public func save(_ file: DayFile) throws             // creates folders; atomic
    public func listDays() throws -> [DayID]             // ascending; ignores files that are not YYYY-MM-DD.md
    @discardableResult public func add(_ text: String, to day: DayID) throws -> Int          // returns 1-based number
    public func setDone(_ ref: TaskRef, _ done: Bool, on day: DayID) throws
    public func edit(_ ref: TaskRef, text: String, on day: DayID) throws
    public func remove(_ ref: TaskRef, on day: DayID) throws
    public func archive(_ ref: TaskRef, on day: DayID) throws
    public func move(_ ref: TaskRef, from: DayID, to: DayID) throws
    public func reorder(_ number: Int, to newNumber: Int, on day: DayID) throws
    public func setFocus(_ ref: TaskRef?, on day: DayID) throws   // nil clears
    public static func normalize(_ text: String) throws -> String  // line breaks -> spaces, trim; throws .emptyText
}
```
Behaviour: every operation does load → change → save. `add` appends after the last task line (or at the end). `setDone(true)` sets `.done`, `doneAt` = local `HH:mm` from `clock`, and clears `isFocus`; `setDone(false)` sets `.open` and clears `doneAt`. `move` appends the task as `.open` to the target day (focus cleared) and marks the source `.moved` with `movedTo`; `from == to` throws `.invalidDate`. `reorder` moves among task lines only; `.other` lines keep their places. `setFocus` on a task that is not `.open` throws `.notFound`. `remove` deletes the line. `normalize` is used by `add` and `edit`. `.number` out of range and `.text` without a match throw `.notFound`; more than one match throws `.ambiguous`.

### Task 5: Notes store and AGENTS.md

**Files:** Create `Sources/MarginCore/NotesStore.swift`, `AgentsDoc.swift`; tests `NotesStoreTests.swift`, `AgentsDocTests.swift`.

**Interfaces — Produces:**
```swift
public struct ArchivedNote: Equatable, Identifiable, Sendable { public let url: URL; public let title: String; public let date: Date; public var id: URL { url } }
public final class NotesStore: @unchecked Sendable {
    public init(root: URL = Store.defaultRoot(), clock: @escaping @Sendable () -> Date = { Date() }, calendar: Calendar = .current)
    public var currentURL: URL { get }                       // root/notes/current.md
    public func current() throws -> String                   // missing -> ""
    public func setCurrent(_ text: String) throws
    public func append(_ text: String) throws                // adds "\n" between when current is not empty
    @discardableResult public func newNote() throws -> ArchivedNote?   // nil when current is empty or whitespace
    public func list() throws -> [ArchivedNote]              // newest first
    public func read(_ note: ArchivedNote) throws -> String
    public func open(_ note: ArchivedNote) throws            // archives current (if not empty), then note becomes current and its archive file is removed
    public func delete(_ note: ArchivedNote) throws
    public func deleteCurrent() throws                       // current becomes ""
}
public enum AgentsDoc {
    public static func text(version: String) -> String
    public static func install(root: URL, version: String) throws   // see rules
}
```
Archive file name: `YYYY-MM-DD-HHmm-<slug>.md`; slug = first non-empty line, lowercased, non-alphanumeric runs → `-`, maximum 40 characters, `note` when empty; when the name exists, add `-2`, `-3`. Title = first non-empty line (maximum 60 characters) or "Untitled". Date is parsed from the file name.
`AgentsDoc.install` rules: write `AGENTS.md` when it does not exist. When it exists, replace it only if its content is equal to the content recorded in `root/.agents-doc` (the last text that Margin wrote); always update `.agents-doc` when writing. `text` covers: folder layout, the day file markers and tags (spec 6.3), every CLI command (spec 7.2), the rule "prefer the `margin` command for changes", and the summary recipe `margin history --done --from <D> --to <D>`.

```swift
public final class MCPServer {

public struct TabPlacement: Codable, Equatable, Sendable { public var edge: ScreenEdge; public var fraction: Double; public var displayID: UInt32 }
public enum EdgeGeometry {
    public static func snap(point: CGPoint, in screen: CGRect, displayID: UInt32) -> TabPlacement
    public static func tabFrame(_ p: TabPlacement, length: CGFloat, thickness: CGFloat, in screen: CGRect) -> CGRect
    public static func panelFrame(tab: CGRect, edge: ScreenEdge, size: CGSize, in visible: CGRect, gap: CGFloat) -> CGRect
    public static func clamp(_ frame: CGRect, into visible: CGRect) -> CGRect

}
```
MCP: JSON-RPC 2.0, one message per line. Methods: `initialize` (reply `protocolVersion` = the version that the client sent, or `2025-06-18` when absent; `capabilities: {"tools": {}}`; `serverInfo: {name: "margin", version: AppInfo.version}`), `notifications/initialized` (no reply), `ping` (empty result), `tools/list`, `tools/call`. Unknown method: error −32601. Invalid JSON: error −32700 with `id: null`. Tools are the 15 names in spec 7.3. Common arguments: `date` (string, optional, same values as the CLI), `task` (integer number or string fragment). A tool result is `{"content":[{"type":"text","text": <JSON string of the day or note after the call>}], "isError": false}`; a `MarginError` gives `isError: true` with the description as text. `get_history` arguments: `from`, `to`, `filter` (`done` | `open` | `all`).
Geometry: coordinates are AppKit screen coordinates (origin bottom-left). `snap` selects the edge with the smallest distance to the point; `fraction` is 0…1 along that edge (left→right for top/bottom, bottom→top for left/right), clamped. `tabFrame` centres the tab on the fraction and then keeps the full tab inside the screen; for left/right the size is `thickness × length`, for top/bottom `length × thickness`. `panelFrame` puts the panel on the inner side of the tab, centred on the tab along the edge, `gap` from the edge, then `clamp`. `clamp` moves the frame inside `visible` and reduces its size when it is larger than `visible`.
